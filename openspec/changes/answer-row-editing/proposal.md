# Proposal

## Why

The custom answer row only types and backspaces. Paste, word delete and
caret moves work in the composer but not there. An answer cannot start with
a digit, because a digit picks a choice.

## What Changes

- The answer row edits with the composer's keys: caret moves, word moves,
  word and line deletes, and Ctrl+V paste.
- Space on an open question opens an empty answer row, so `3 files` can be
  typed.

## Keyboard and resources

No new keys: the composer's keys apply in one more place. Space was
unused on a question.
